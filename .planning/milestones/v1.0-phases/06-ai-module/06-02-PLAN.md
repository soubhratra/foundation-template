```python
def search_documents(
    query: str,
    limit: int = 5,
    filters: dict | None = None,
    similarity_threshold: float = 0.7,
) -> list[dict]:
```

Implementation (following research Pattern 4):

1. Generate query embedding using OpenAI API (same model as chunks: text-embedding-3-small)
2. Build QuerySet starting with DocumentChunk.objects.exclude(embedding\_\_isnull=True)
3. Apply metadata filters if provided using JSONField lookups: `queryset.filter(metadata__[key]=value)`
4. Annotate with CosineDistance and convert to similarity: `similarity = 1 - (F("distance") / 2)`
5. Filter by similarity_threshold: `filter(similarity__gte=similarity_threshold)`
6. Order by distance (ascending = most similar first)
7. Limit results and select fields: id, text, similarity, metadata, document\_\_title, document_id, chunk_index
8. Return list of dicts

Handle edge cases:

- Empty query → return empty list
- No results above threshold → return empty list (not error, per research recommendation)
- OpenAI API errors → log and re-raise (caller handles)

Use cosine similarity conversion from research to avoid anti-pattern: PGVector returns distance (0-2), convert to similarity (0-1).
</action>
