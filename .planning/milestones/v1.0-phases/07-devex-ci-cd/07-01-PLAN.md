Add pre-commit framework to root and configure hooks for multi-language monorepo.

**Python setup (apps/api/pyproject.toml):**

- Add `pre-commit` to dev dependency group (version 4.x)
- Run `cd apps/api && uv sync` to install

**Root package.json:**

- Add `pre-commit` script: `pre-commit run --all-files`
- Verify `lint-staged` config already exists (added in Phase 1)

**Create .pre-commit-config.yaml at repo root:**

```yaml
repos:
  # Python quality (ruff replaces black + flake8 + isort)
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.15.1
    hooks:
      - id: ruff
        args: [--fix] # Auto-fix linting issues
      - id: ruff-format # Format Python code

  # JS/TS quality (via lint-staged to scope to changed files only)
  - repo: local
    hooks:
      - id: lint-staged
        name: lint-staged
        entry: pnpm lint-staged
        language: system
        pass_filenames: false

  # General hygiene
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v5.0.0
    hooks:
      - id: trailing-whitespace
      - id: end-of-file-fixer
      - id: check-yaml
      - id: check-added-large-files
        args: ["--maxkb=500"]
      - id: check-merge-conflict
```

**Design decision (auto-fix):** Hooks auto-fix format and lint issues for developer convenience. Type errors block without auto-fix (require developer understanding). Research shows this balances speed and control.

**Design decision (changed files only):** Pre-commit runs only on staged files by default (< 5s typical). CI runs full codebase checks. This keeps local feedback fast per research recommendations.

Install hooks: Run `cd apps/api && uv run pre-commit install` to activate.

Configure ruff for Python and add type-check tasks across the monorepo.

**Create apps/api/ruff.toml:**

```toml
# Ruff configuration for Python linting and formatting
line-length = 100
target-version = "py312"

[lint]
select = [
    "E",   # pycodestyle errors
    "W",   # pycodestyle warnings
    "F",   # pyflakes
    "I",   # isort
    "B",   # flake8-bugbear
    "C4",  # flake8-comprehensions
    "UP",  # pyupgrade
]
ignore = []

[lint.isort]
known-first-party = ["apps", "config"]
```

**Add type-check task to turbo.json:**

```json
{
  "tasks": {
    "type-check": {
      "cache": true,
      "dependsOn": ["^build"]
    }
  }
}
```

**Add type-check scripts to app package.json files:**

apps/web/package.json:

```json
{
  "scripts": {
    "type-check": "tsc --noEmit"
  }
}
```

apps/mobile/package.json:

```json
{
  "scripts": {
    "type-check": "tsc --noEmit"
  }
}
```

**Design decision (ruff config):** Using ruff as single tool for format + lint replaces black + flake8 + isort. Research shows ruff is 10-100x faster and now standard for Python projects.

**Design decision (type-check in turbo):** Centralized `turbo type-check` runs TypeScript checks across all apps. Python type checking (mypy) runs separately in API tests due to Django-specific configuration.

mypy configuration already exists in apps/api/pyproject.toml from Phase 2 (no changes needed).
