<objective>
Fix the 3 failing service tests caused by a naming mismatch between migration 0002 (which seeded `price_stub_pro_monthly`) and the conftest plan_mapping fixture (which expected `price_pro_monthly`).

**Root cause:** Migration 0002 seeded `price_id="price_stub_pro_monthly"` for the pro/stub/monthly PlanProviderMapping row. The conftest `plan_mapping` fixture uses `get_or_create` with `defaults={"price_id": "price_pro_monthly"}`. Since the migration row already exists when tests run, `get_or_create` returns the migration row — with its `"price_stub_pro_monthly"` value — so the fixture defaults are never applied. Three test assertions that expected `"price_pro_monthly"` then fail.

**Fix:** Update conftest.py fixture defaults AND test assertions to use `"price_stub_pro_monthly"`, aligning tests with the migration-seeded value (the canonical source of truth in the DB).

No production behavior changes — this is test infrastructure only.
</objective>
