## Tech Debt by Phase

### Phase 21: GDPR Baseline — 2 items

**1. UserDeletionService duplication**

`UserDeletionService.execute()` in `services.py` and `delete_user_account` Celery task in `tasks.py` both implement the same 4-step cascade (cancel subscription → delete Stripe customer → delete PostHog person → `user.delete()`) independently. The task does not delegate to the service. Future cascade changes must be applied in two places.

_Recommendation:_ Have `delete_user_account` delegate to `UserDeletionService.execute()`.

**2. Missing "Download my data" UI button**

`GET /api/v1/account/export` returns a JSON attachment with `Content-Disposition: attachment; filename="my-data.json"`. No link or button exists in `apps/web/app/(dashboard)/settings/settings-client.tsx` to trigger it. The endpoint is reachable via direct URL by authenticated users.

_Recommendation:_ Add a "Download my data" button in the /settings DangerZone section alongside the Delete Account button.

### Phase 22: RBAC — 2 items

**3. AdminController missing `auth=` parameter**

`AdminController` at `apps/api/apps/accounts/controllers.py` has no `auth=[SessionAuth(), jwt_token_auth]` parameter. Auth relies entirely on Django middleware. Documented as deliberate in 22-03-SUMMARY.md, but departs from the `[SessionAuth(), jwt_token_auth]` pattern on `UserController` and `AccountController`.

_Recommendation:_ Add `auth=[SessionAuth(), jwt_token_auth]` to `AdminController` for defense-in-depth consistency.

**4. Migration filename convention deviation (RBAC-03)**

`migration_0003_seed_roles.py` uses a non-standard prefix. Django discovers and runs it correctly (the loader filters on `_` and `~` prefixes, not `m`). The internal migration name is `migration_0003_seed_roles`. No other migration declares a dependency on it, so no resolution failures occur. However, future developers expecting conventional `0003_seed_roles.py` naming may be confused.

_Recommendation:_ Rename to `0003_seed_roles.py` in a future cleanup phase (requires a no-op migration rename, which is safe in Django).

### Total: 4 items across 2 phases
