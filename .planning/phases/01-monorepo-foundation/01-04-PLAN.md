  <action>
Create .env.example files for frontend apps and update root package.json with convenience scripts.

1. **apps/web/.env.example** -- Next.js env template:
   ```bash
   # apps/web/.env.example
   # Copy to .env.local for local development

   # API connection
   NEXT_PUBLIC_API_URL=http://localhost:8000
   ```

2. **apps/mobile/.env.example** -- Expo env template:
   ```bash
   # apps/mobile/.env.example
   # Copy to .env for local development

   # API connection (use your machine's local IP for physical device testing)
   EXPO_PUBLIC_API_URL=http://localhost:8000
   ```

3. **Update root package.json scripts** to add convenience commands. Read the existing package.json first, then add these scripts while preserving existing ones:
   ```json
   {
     "scripts": {
       "dev": "turbo dev",
       "build": "turbo build",
       "lint": "turbo lint",
       "test": "turbo test",
       "type-check": "turbo type-check",
       "clean": "turbo clean",
       "format": "prettier --write \"**/*.{ts,tsx,js,jsx,json,md,yml,yaml}\"",
       "db:up": "docker compose up -d",
       "db:down": "docker compose down",
       "db:migrate": "cd apps/api && uv run python manage.py migrate",
       "db:makemigrations": "cd apps/api && uv run python manage.py makemigrations",
       "db:reset": "docker compose down -v && docker compose up -d && sleep 5 && cd apps/api && uv run python manage.py migrate",
       "setup": "pnpm install && cd apps/api && uv sync && cd ../.. && docker compose up -d && sleep 5 && cd apps/api && uv run python manage.py migrate"
     }
   }
   ```

   Key scripts explained:
   - `dev`: Delegates to `turbo dev` which starts all apps in parallel
   - `db:up` / `db:down`: Start/stop Docker infrastructure
   - `db:migrate` / `db:makemigrations`: Django migration shortcuts
   - `db:reset`: Nuclear option -- destroys volumes and recreates from scratch
   - `setup`: One-command setup for new developers (install deps, start infra, run migrations)

4. **Verify turbo dev works** by running it from repo root. It should start:
   - @repo/api: Django runserver on port 8000
   - @repo/web: Next.js dev server on port 3000
   - @repo/mobile: Expo Metro bundler

   NOTE: Docker services (Postgres, Redis) must already be running via `docker compose up -d`. turbo dev only starts application processes.

   Run `pnpm dev` and verify all three processes start with workspace-prefixed output. Each process should show its startup message:
   - Django: "Starting development server at http://0.0.0.0:8000/"
   - Next.js: "Local: http://localhost:3000"
   - Expo: "Metro waiting on..."

5. **Update .gitignore** if needed -- ensure these env files are ignored:
   - `.env` (root)
   - `apps/api/.env`
   - `apps/web/.env.local`
   - `apps/mobile/.env`

   But NOT:
   - `.env.example` (any location -- these are committed)
