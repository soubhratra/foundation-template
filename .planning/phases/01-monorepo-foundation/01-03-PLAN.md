1. **apps/web/package.json**:
   ```json
   {
     "name": "@repo/web",
     "version": "0.0.0",
     "private": true,
     "scripts": {
       "dev": "next dev --turbopack --port 3000",
       "build": "next build",
       "start": "next start",
       "lint": "eslint .",
       "type-check": "tsc --noEmit"
     },
     "dependencies": {
       "next": "^15.1.0",
       "react": "^19.0.0",
       "react-dom": "^19.0.0"
     },
     "devDependencies": {
       "@repo/config-ts": "workspace:*",
       "@repo/config-eslint": "workspace:*",
       "typescript": "^5.7.0",
       "eslint": "^9.0.0",
       "@types/react": "^19.0.0",
       "@types/react-dom": "^19.0.0",
       "tailwindcss": "^4.0.0",
       "@tailwindcss/postcss": "^4.0.0"
     }
   }
   ```

   NOTE: Tailwind CSS 4 uses `@tailwindcss/postcss` plugin (not the old tailwindcss postcss plugin). The `tailwind.config.ts` is optional in v4 (CSS-first configuration), but we include it for explicit customization.

2. **apps/web/tsconfig.json** -- Extends shared config:
   ```json
   {
     "extends": "@repo/config-ts/nextjs.json",
     "compilerOptions": {
       "baseUrl": ".",
       "paths": {
         "@/*": ["./*"]
       }
     },
     "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".next/types/**/*.ts"],
     "exclude": ["node_modules"]
   }
   ```

3. **apps/web/next.config.ts** -- Minimal for now (React Native Web transpile will be added in Phase 3/4):
   ```typescript
   import type { NextConfig } from "next";

   const nextConfig: NextConfig = {
     transpilePackages: [],
   };

   export default nextConfig;
   ```

4. **apps/web/postcss.config.mjs** -- Tailwind CSS 4 PostCSS plugin:
   ```javascript
   const config = {
     plugins: {
       "@tailwindcss/postcss": {},
     },
   };

   export default config;
   ```

5. **apps/web/tailwind.config.ts** -- Tailwind v4 still supports config file for customization:
   ```typescript
   import type { Config } from "tailwindcss";

   const config: Config = {
     content: ["./app/**/*.{ts,tsx}", "./components/**/*.{ts,tsx}"],
     theme: {
       extend: {},
     },
     plugins: [],
   };

   export default config;
   ```

6. **apps/web/app/globals.css** -- Tailwind CSS 4 import:

   ```

     );
   }
   ```
