5. Create `apps/api/apps/audit/middleware.py`:

```python
"""AuditContextMiddleware: extends pghistory HistoryMiddleware to add org_id.

Built-in HistoryMiddleware captures: user (PK of request.user), url.
This subclass adds: org_id from request.org (set by IsOrgMember/IsOrgAdmin).

impersonator context key is NOT set here — Phase 30 (django-hijack signals)
will inject it via pghistory.context(impersonator=...) in a signal receiver.
"""
import pghistory.middleware


class AuditContextMiddleware(pghistory.middleware.HistoryMiddleware):
    """Extend HistoryMiddleware to capture org_id on org-scoped requests."""

    def get_context(self, request):
        ctx = super().get_context(request)
        # request.org is set by IsOrgMember/IsOrgAdmin permission classes.
        # May be None for non-org endpoints — guard accordingly.
        org = getattr(request, "org", None)
        if org is not None:
            ctx["org_id"] = org.pk
        return ctx
```

Add `@pghistory.track()` decorators to each of the four tracked models. Apply each decorator to the existing class in-place. Use the exact pgh_label strings specified below — they are the canonical action identifiers exposed by the audit log API (changing them later invalidates existing records).

**apps/orgs/models.py — Organization:**
Add `import pghistory` at the top of the file (after existing imports).
Add decorator directly above the `class Organization` definition:

```python
@pghistory.track(
    pghistory.InsertEvent("org.created"),
    pghistory.UpdateEvent("org.updated"),
    pghistory.DeleteEvent("org.deleted"),
    exclude=["updated_at"],
)
class Organization(models.Model):
```
