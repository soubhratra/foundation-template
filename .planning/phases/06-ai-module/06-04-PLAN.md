**remove_ai_module.sh:** Automated removal script
```bash
#!/bin/bash
set -e

echo "=== AI Module Removal Script ==="
echo ""
echo "This script will:"
echo "  1. Remove apps.ai from INSTALLED_APPS"
echo "  2. Run migration to drop ai tables"
echo "  3. Remove ai/ directory"
echo "  4. Run verification checks"
echo ""
read -p "Continue? (y/n) " -n 1 -r
echo
if [[ ! $REPLY =~ ^[Yy]$ ]]; then
    exit 1
fi

# Step 1: Remove from settings (sed or manual instruction)
echo "Step 1: Removing apps.ai from INSTALLED_APPS..."
sed -i.bak '/apps.ai/d' config/settings/base.py
echo "✓ Removed from INSTALLED_APPS"

# Step 2: Drop database tables
echo "Step 2: Dropping AI module database tables..."
python manage.py migrate ai zero
echo "✓ Database tables dropped"

# Step 3: Remove directory
echo "Step 3: Removing apps/ai/ directory..."
rm -rf apps/ai/
echo "✓ Directory removed"

# Step 4: Verify removal
echo "Step 4: Running verification checks..."
bash apps/ai/scripts/verify_removal.sh
echo ""
echo "=== Removal Complete ==="
echo "Don't forget to:"
echo "  - Remove dependencies: pgvector, langgraph, langchain-*, celery, openai, tiktoken"
echo "  - Update pyproject.toml and run: uv sync"
```

**verify_removal.sh:** Verification script (from research Removal Verification Script example)
```bash
#!/bin/bash
set -e

echo "=== AI Module Removal Verification ==="

# 1. Check for imports from ai/ in other apps
echo "Checking for external dependencies on ai module..."
if grep -r "from apps.ai" apps/ --exclude-dir=ai --exclude-dir=__pycache__ --exclude="*.pyc" 2>/dev/null; then
    echo "ERROR: Found imports from ai/ in other apps"
    exit 1
fi

if grep -r "import apps.ai" apps/ --exclude-dir=ai --exclude-dir=__pycache__ --exclude="*.pyc" 2>/dev/null; then
    echo "ERROR: Found imports of ai module in other apps"
    exit 1
fi

echo "✓ No external dependencies found"

# 2. Run tests without ai module
echo "Running tests with ai module excluded..."
pytest apps/ --ignore=apps/ai --tb=short -q || true
echo "✓ Tests completed"

# 3. Check linting
echo "Running linting without ai module..."
ruff check apps/ --exclude apps/ai || true
echo "✓ Linting completed"

echo ""
echo "=== Verification Complete ==="
```

Make both scripts executable: `chmod +x apps/api/apps/ai/scripts/*.sh`
