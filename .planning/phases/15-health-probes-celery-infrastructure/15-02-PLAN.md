  <files>apps/api/apps/core/health.py, apps/api/apps/core/health_urls.py</files>
  <action>
    Create apps/api/apps/core/health.py with three plain Django view functions.
    Do NOT use Ninja schemas or ControllerBase — plain JsonResponse views only.
    No authentication required (AllowAny equivalent — just return the response).

    **live_view(request):**
    - Always returns 200 with {"status": "alive"}
    - Purpose: liveness probe — if this returns, the process is not wedged
    - No external checks — any exception here means the process itself is broken

    **ready_view(request):**
    - Checks Postgres, Redis, and Celery in sequence; collects all results
    - Postgres check: `from django.db import connection; connection.cursor().execute("SELECT 1")` — on exception, record "error: <str(e)>"
    - Redis check: `import redis; redis.Redis.from_url(settings.REDIS_URL).ping()` — on exception, record "error: <str(e)>"
    - Celery check: `from config.celery import app as celery_app; inspect = celery_app.control.inspect(timeout=1.0); pong = inspect.ping(); ok = bool(pong)` — on exception or empty result, record "error: no workers"
    - If ALL checks are "ok" → return 200 {"status": "ready", "checks": {...}}
    - If ANY check failed → return 503 {"status": "degraded", "checks": {...}}
    - Each check value is either the string "ok" or the string "error: <message>"

    **startup_view(request):**
    - Uses Django's migration executor to count unapplied migrations:
      ```python
      from django.db.migrations.executor import MigrationExecutor
      from django.db import connection
      executor = MigrationExecutor(connection)
      plan = executor.migration_plan(executor.loader.graph.leaf_nodes())
      pending = len(plan)
      ```
    - If pending == 0 → return 200 {"status": "ready", "pending_migrations": 0}
    - If pending > 0 → return 503 {"status": "pending", "pending_migrations": pending}
    - Wrap in try/except: if DB unreachable, return 503 {"status": "error", "pending_migrations": -1}

    Create apps/api/apps/core/health_urls.py:
    ```python
    from django.urls import path
    from apps.core.health import live_view, ready_view, startup_view

    urlpatterns = [
        path("live", live_view, name="health-live"),
        path("ready", ready_view, name="health-ready"),
        path("startup", startup_view, name="health-startup"),
    ]
    ```
