    **Append the following fixture to `apps/api/conftest.py` AFTER the existing macOS DYLD block:**

    ```python
    import pytest


    # --- nplusone: N+1 query detection (DEV-04) ---
    # This autouse fixture activates nplusone for EVERY pytest test in apps/api.
    # Any queryset accessed in a loop will raise nplusone.core.exceptions.NPlusOneError
    # unless the test function is decorated with @allow_lazy_load.
    #
    # To annotate an intentional N+1 (document it in code review):
    #   from nplusone.ext.pytest import allow_lazy_load
    #
    #   @allow_lazy_load
    #   def test_something_with_intentional_n_plus_one():
    #       ...
    @pytest.fixture(autouse=True)
    def _nplusone_guard(nplusone):
        """Raise NPlusOneError on any N+1 query detected in this test."""
        nplusone.assert_no_n_plus_one()
    ```

    The `nplusone` fixture argument is provided by the nplusone pytest plugin (registered
    automatically when nplusone is installed). The `_nplusone_guard` fixture wraps it as
    `autouse=True` so it applies to all tests without explicit use.

    The `nplusone.assert_no_n_plus_one()` call is made at fixture teardown (after the test body),
    so it does not block test setup. N+1 detection happens during the test body; the assertion
    raises NPlusOneError at teardown if any N+1 was detected.
