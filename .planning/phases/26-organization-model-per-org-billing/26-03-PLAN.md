```python
from django.http import HttpRequest
from ninja_extra import ControllerBase
from ninja_extra.permissions import BasePermission

class RequireRole(BasePermission):
    def __init__(self, role: str) -> None:
        self.role = role

    def has_permission(self, request: HttpRequest, controller: ControllerBase) -> bool:
        user = getattr(request, "user", None)
        if not user or not user.is_authenticated:
            return False
        if not user.groups.filter(name=self.role).exists():
            return False
        return True
```

IsOrgMember shape from RESEARCH.md (verified pattern):

- Extract org_slug from `request.resolver_match.kwargs.get("org_slug", "")`
- Organization not found → raise Http404
- User not a member → raise Http404 (leaks no org existence)

IsOrgAdmin shape from RESEARCH.md (verified pattern):

- Read `request.org` (set by IsOrgMember — do NOT re-query)
- Member not found with role in ["owner", "admin"] → raise PermissionDenied
- On success → return True

Composition rule (CRITICAL — from RESEARCH.md Pitfall 3):

- Admin endpoints MUST use: `permissions=[IsAuthenticated, IsOrgMember, IsOrgAdmin]`
- NEVER use IsOrgAdmin alone — request.org would be unset
- Document this constraint in IsOrgAdmin class docstring
